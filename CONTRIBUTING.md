# Contributing to Tiharqa Film Production Website

Thank you for contributing to the Tiharqa Film Production website.

This project represents the digital presence of **Tiharqa Film Production**, so every contribution should maintain a high standard of quality, performance, accessibility, and brand consistency.

---

## Core Principles

When making changes to this codebase:

* Preserve the visual design system, layout, and component aesthetics
* Preserve the Tiharqa Film brand identity and Ethiopian cinema focus
* Keep the code clean, fast, accessible, and responsive
* Test builds with `npm run build` before opening a pull request
