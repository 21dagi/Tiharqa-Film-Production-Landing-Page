# Security Policy

## Tiharqa Film Production Website

Security and privacy are core requirements of the Tiharqa Film Production website and its supporting infrastructure.

### Reporting a Vulnerability

If you discover a security vulnerability or privacy issue, please disclose it responsibly by contacting:

**[contact@tiharqafilm.com](mailto:contact@tiharqafilm.com)**

We appreciate responsible disclosures that help keep the platform safe for all visitors.
